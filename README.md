### Core Research Pillars

2. **Modern Machine Learning & AI:** Score-based diffusion models (continuous-time SDEs), physics-informed neural networks (PINNs), operator learning (Fourier Neural Operators).
3. **Quantum Theory & Quantum Technology:** Quantum state tomography, open quantum systems, path integrals, quantum circuits.
4. **Computational Physics & HPC:** High-performance computing, GPU-accelerated spectral methods, parallel Navier-Stokes solvers (CUDA, PyTorch, C++).
