Fluid Dynamics // Inverse PINN Flagship Pipeline

Navier-Stokes Inverse Problem Solver

Reconstructed complete 2D velocity vectors \((u, v)\) and continuous latent pressure fields \(p\) from sparse, noisy velocity measurements inside a wake behind a cylinder. The network minimizes continuous Navier-Stokes momentum residuals via PyTorch autograd while simultaneously estimating latent fluid parameters like kinematic viscosity \(\nu\).

$$\mathcal{L}_{\text{total}} = \frac{1}{N_d}\sum_{i=1}^{N_d} \Big(|u(x_i) - u_i^*|^2 + |v(x_i) - v_i^*|^2\Big) + \lambda \Big(\|\partial_t u + u u_x + v u_y + p_x - \nu \nabla^2 u\|_2^2 + \|\partial_t v + u v_x + v v_y + p_y - \nu \nabla^2 v\|_2^2\Big)$$

Operator Learning // Wave Mechanics Zero-Shot Resolution

Fourier Neural Operators (FNO-1D)

Implemented mesh-independent operator learning for time-dependent Burgers' and 1D wave equations. By parameterizing kernel integration directly in the frequency domain via Fast Fourier Transforms (FFT) and truncating higher modes, the model maps initial functional states to continuous trajectories with zero-shot generalization across spatial grid resolutions.

$$(\mathcal{K}(v))(x) = \mathcal{F}^{-1}\Big(R_\theta \cdot (\mathcal{F} v)\Big)(x) \quad \text{where } R_\theta \in \mathbb{C}^{k_{\max} \times d_{\text{in}} \times d_{\text{out}}}$$

Numerical Benchmarks // Computational Limits HPC Analysis

Automatic Differentiation vs Classical CFD Stencils

An empirical and theoretical benchmark comparing reverse-mode Automatic Differentiation (PyTorch dynamic computation graph tape) against 2nd-order and 4th-order central finite difference stencils. Evaluates peak GPU VRAM allocation, floating-point error scaling, and runtime throughput when computing spatial derivatives on \(1024 \times 1024\) grids.

$$\text{FD: } \mathcal{O}(1) \text{ Memory Overhead, Truncation Error } \mathcal{O}(h^2) \quad \longleftrightarrow \quad \text{Autograd: Machine Precision, Graph Memory } \mathcal{O}(N \times \text{Depth})$$

Physics-Informed ML // Optimization Theory Stiff Systems

Physics-Informed Neural Networks for Stiff PDEs

Investigating failure modes and gradient imbalances in multi-objective PINN optimization. When boundary conditions and multiscale PDE residuals compete, standard Adam updates suffer from spectral bias and gradient vanishing. We implement adaptive gradient-norm loss reweighting and random Fourier feature embeddings to stabilize convergence.

$$\lambda_k^{(t+1)} = (1 - \alpha)\lambda_k^{(t)} + \alpha \frac{\max_j \overline{\|\nabla_\theta \mathcal{L}_j\|}}{\overline{\|\nabla_\theta \mathcal{L}_k\|}} \quad \text{[Adaptive Learning Rate Annealing]}$$
